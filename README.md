# 대한민국 주화 발행량 도감

## 실행
- `index.html`을 브라우저에서 열면 작동합니다.
- 인터넷 연결 없이도 기본 기능은 동작합니다. (웹폰트는 연결 시 적용)
- GitHub Pages에 폴더 안의 파일을 그대로 올리면 배포할 수 있습니다.

## 폴더 구성
- `index.html`: 화면 구조
- `style.css`: 디자인 및 반응형 레이아웃
- `app.js`: 주화 선택, 연도 검색, 정렬, 발행량 색상 처리
- `data.js`: 연도별 발행량 데이터
- `images/hero-bg.png`: 상단 배경
- `images/coins/`: 주화 버튼 이미지 7개

## 데이터 주의
연도별 발행량은 사용자가 제공한 3장의 표(1966~2026)를 옮긴 1차 입력 자료입니다. 공식 통계와 전수 대조가 완료된 데이터가 아닙니다. 특히 2026년은 원본 표에 '추정'으로 기재되어 있어 화면에서도 추정으로 표시합니다.
2006년 10원은 구형 40,800,000개와 신형 109,200,000개로 분리했습니다.

## 발행량 색상
- 1만 개 이하: 빨강
- 5만 개 이하: 주황
- 10만 개 이하: 노랑
- 50만 개 이하: 초록
- 100만 개 이하: 파랑
- 500만 개 이하: 남색
- 1,000만 개 이하: 보라
- 1,000만 개 초과: 중립 회색

## 수정 방법
연도별 수량을 수정하려면 `data.js`의 `rows` 배열을 수정합니다.
`null`은 원본 표에서 '미발행'으로 표시된 항목입니다.
